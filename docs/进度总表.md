> - **迭代 2(2026-08-26)新增**:
>   - **东财 push2 主机有 IP 级 WAF 限流**:池端点(push2ex)稳定,指数(push2 stock/get)偶通,ulist.np/clist/f6 持续 SSL RST。策略 = 池数据必须、其余尽力而为,失败如实 pending(宁缺毋假,§5.8)。
>   - **复盘页幂等坑**:行业 top-N 曾只按 count 排序(Go map 随机序破坏重跑零提交),加 name 次级排序修复(commit `2daf48e`)。
>   - **情绪阈值初版,~20 交易日真实数据后校准**(架构 §9.8)。
> - **迭代 3(2026-08-26)新增**:实体层走**单表 `entities`(type 判别 + detail JSONB)**,复用 relationships 多态(不新建关系表);实体构建 = 种子源零 AI(zt_pool → Company/Industry)+ 事件 affected 未命中词便宜档批量分类一次(拿不准 → `unknown` 不猜);行业仅叶子(不建 parent 链);G3 巨潮/财务/宏观明确延后。
> - **聚类质量(2026-08-28)新增**:
>   - **重审视 Pass 不降阈值**:跨簇重复根因是结构性盲区(候选池缺既有 canonical),非阈值过紧;重审视复用迭代 1 三关(同类型 + Jaccard≥0.7 或实体交集+3天 + LLM 确认),只扩候选池不降门槛,防过度合并。
