# PIKS 数据源总览

> **本文是 PIKS 全部取数链路的现状清单——以代码为准。**
> 核对:2026-09-20(dev `82ad02d`)。架构全貌见 `docs/架构总览.md`,数据源扩展计划见 `research/docs/plan-data-source-integration.md`。
>
> **一句话结论**:全库只有 **2 个 Go 采集入口(都是东方财富)** + **1 套按需的 Python/akshare 抓取**;
> 其余命令全部读库派生,不碰外网。

---

## 1. 三条真实取数链路

| 链路 | 语言 | 源 | 触发 | 代码 |
|---|---|---|---|---|
| **A 快讯** | Go `cmd/collector` | 东方财富 7x24 快讯 | cron 日管线 | `internal/collector/dongcai.go` |
| **B 涨停池/指数** | Go `cmd/quote-collector` | 东方财富 push2ex / push2 | cron 日管线 | `internal/collector/quotemarket.go` |
| **C 研报数据** | Python `research/` | akshare(腾讯 / 申万 / NBS 等多方) | **按需**(UI 或 CLI),**不进 cron** | `research/src/providers/**` |

**其余命令**(`worker` / `cluster` / `entity-build` / `market-state` / `daily-review` / `reconcile`)
**都是读库派生,零外网**。

## 2. 数据种类 → 来源 → 代码 → 频率

### 2.1 日管线采集(有外网)

| 数据 | 来源 | 代码落点 | 频率 |
|---|---|---|---|
| **快讯** `flashes` | 东财 `np-weblist.eastmoney.com/.../getFastNewsZhibo`(网页内部接口,游标翻页,单次 1 页≈50 条) | `internal/collector/dongcai.go:21`(URL)、`:62-78`(Fetch)、`:110-122`(归一化)、`:132-139`(北京时间解析);入口 `cmd/collector/main.go:22`(`-driver dongcai`) | 每交易日 1 次,16:10 后 |
| **涨停/炸板/跌停池** `ladder` | 东财 `push2ex.eastmoney.com/getTopicZTPool` / `getTopicZBPool` / `getTopicDTPool` | `internal/collector/quotemarket.go:63-67`(端点)、`:118-180`(Fetch 聚合) | 每交易日 1 次,非交易日自动跳过 |
| **指数 / 成交额 / 涨跌家数** | 东财 `push2.eastmoney.com/api/qt/stock/get`(成交额、家数端点**持续被 WAF 挡**) | `quotemarket.go:246`(指数)、`:260`(家数)、`:280`(成交额)、`:297-330`(`getJSON` 重试退避) | 同上;取不到如实记 `pending` |

**落库**:快讯 → `sources`(name=`news-flash`) → `raw_documents`(`UNIQUE(source_id, content_hash)` sha256 去重);
涨停池/指数 → `observations`(12 个指标,`cmd/quote-collector/main.go:74-118`;指标字典 `internal/marketstate/marketstate.go:14-28`)。

**健康**:连续失败 3 次 → `PauseSource`(`cmd/collector/main.go:58-71`)。

### 2.2 日管线派生(零外网)

| 数据 | 来源 | 代码 | 频率 |
|---|---|---|---|
| **事件** `events` | ⚠️ **无外部源** —— 由快讯经 LLM 结构化抽取 | `internal/extract/extract.go` + `prompts/extract.md`;入口 `cmd/worker` | 每交易日 1 次,单次 ≤50 条(`-limit`),受日 token 预算护栏 |
| **聚类** `event_clusters` | 纯语义去重(无外网) | `cmd/cluster` + `internal/cluster/` | 同上 |
| **实体** `entities` | 种子 = 最近 30 交易日**涨停池** → Company + 东财行业(`hybk`);收割 = 事件 `affected` 词 | `cmd/entity-build/main.go:247`(`harvestSeeds`)、调用在 `:82-140`;分类器 `internal/entityextract/` | 每交易日 1 次,幂等全量派生 |
| **市场情绪** `market_snapshots` | 纯规则派生(读当日 `observations` + 昨快照) | `internal/marketstate/marketstate.go`(`ComputeSnapshot`) | 每交易日 1 次 |
| **复盘 / 对账** | 读库派生 | `cmd/daily-review` / `cmd/reconcile` | 每交易日 1 次 |

> ⚠️ `marketstate.go:374`:情绪模型第「10 资金」项标注**「源待定,如实留空」**——日管线**不复现资金面**。
> 龙虎榜只在研报按需链路(§3)。

### 2.5 一个重要事实:PG 里没有全市场行情表

`observations` 只有指数 `index_close` / `index_pct`(且 push2 被 WAF 限流,尽力而为)。
**个股 K 线 / 量价只存在于 research 运行时**(腾讯 `stock_zh_a_hist_tx`),
随研报落 `research_runs.metrics` JSONB。换手率口径 = A股流通股本(与同花顺一致)。

## 3. 定时任务

定义处:`scripts/setup.sh:33-36`(部署时幂等追加到 lab `rguo@192.168.0.202`)。

```
*/15 * * * *  /home/rguo/piks/scripts/pipeline.sh   >> logs/cron.log 2>&1
59 23 * * *   /home/rguo/piks/scripts/backup.sh     >> logs/cron.log 2>&1
```

| 任务 | cron 层 | 实际频率 | 内容 |
|---|---|---|---|
| `scripts/pipeline.sh` | 每 15 分钟 | **每交易日 1 次**(16:10 后) | 9 步日管线 |
| `scripts/backup.sh` | 每天 23:59 | 每天 | `pg_dump -Fc`,保留 14 天 |

**管线闸门**(`scripts/pipeline.sh:9-24`):

1. 日期锚取 GitHub `curl -sI https://api.github.com` 的 **`Date` 响应头**(免疫宿主机时钟漂移),取不到回退系统时钟并打 WARN;
2. 周末(`DOW>=6`)跳过;
3. 北京时间 < 16:10 跳过;
4. `logs/pipeline-$TODAY.done` 已存在跳过(防重跑);
5. 任一步失败 → **记录不阻断**。

**九步**(`scripts/pipeline.sh:39`),每步 `docker compose run --rm -T tools ./bin/<cmd>`:

```
migrate → collector -driver dongcai → worker → cluster
→ quote-collector -date $TODAY → entity-build → market-state -date $TODAY
→ daily-review -date $TODAY → reconcile -date $TODAY
```

> ⚠️ `scripts/health.sh`(管线完整性自检)注释写「可挂 cron」,但**实际未装进 crontab**,只能手跑。
> 调度器代码层**无**(无 cron 库 / 无 systemd timer);任务记账走 PG `task_runs` 表。

## 4. 凭据

**所有行情 / 财务 / 宏观数据源都不需要 key**:

- **Go 侧** = 东财网页内部接口(无 key、无 SLA,仅需伪造 `User-Agent` + `Referer`,见 `quotemarket.go:305`);
- **Python 侧** = akshare 免费封装(无 key / token)。

**唯一需要凭据的外呼 = LLM 网关**(OpenAI 兼容;生产走 OpenCode Zen,base URL **必须带 `/go`**)。
配置**权威源 = PG `app_config` 表**(`ai_service_base_url` / `ai_api_key` / `ai_model_*` / `ai_daily_token_budget`),
`/settings` 页可编辑,**不读环境变量**(`internal/store/app_config.go:38-45` + `config.ApplyAppConfig`)。

> 生产 `.env` 只需 `PIKS_DB_PASSWORD`(`configs/.env.prod.example:5-7`);
> `.env.local` 里的 `PIKS_AI_*` 是**遗留,Go 代码不读**。
