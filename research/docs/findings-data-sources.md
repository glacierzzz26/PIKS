## 三、公告正文（已知缺口）可行性

- 现公告源为**东财 notices HTML 详情页**（32KB，非 PDF），页面含 `notice_content` 字段标记
- 正文提取两条路：① HTML/JSON 字段解析（轻）；② PDF 直链（`pdf.dfcfw.com`）+ pdfplumber（重）
- 结论：**可行，需一次开发**。完成后事件重大性分级可从「标题关键词」升级为「内容判断」

## 四、通用风险

1. 免费源无 SLA：需 sleep 限频 + 指数退避重试 + 本地 parquet/sqlite 缓存
2. 字段口径：两融单位为**元**（融资余额 109 亿级原始值），龙虎榜为万元，入 analysis 前需归一
3. 东财接口分域名，部分域被限制：任何新接口接入前先跑本 spike 验证
4. 同一指标多源数值可能有差异（如毛利率），交叉验证冲突时记 Evidence 双源

## 五、建议接入优先级

- **P0（修缺口，1-2 天）**：腾讯快照估值 → 新浪/东财现金流（经营现金流+交叉验证）→ 同花顺摘要补毛利率 → 腾讯指数（相对收益）
- **P1（新维度，3-5 天）**：个股资金流 + 两融 → 合并出「资金面」section；预约披露+业绩预告进事件前瞻；股东户数+分红；新浪日线接 failover
- **P2（深度，1 周+）**：研报评级（Opinion tier）；涨停池情绪温度计；公告正文提取升级事件降噪；delta 复研
