# 换手率口径实测结论（issue #4 收口依据）

> 2026-09-18 实测 akshare 1.18.94 + 直连腾讯/东财/同花顺，lab 生产网。
> 以下每条都是**跑出来的**，不是查文档得来的。
> 结论：issue #4「改用自由流通口径」**前提不成立** —— PIKS 现口径已与同花顺一致，且自由流通口径无免费源。故**不改口径**，只修正会误导为「两套口径」的措辞。

## 1. 问题回顾（issue #4 的前提）

issue 的判断链是：

1. PIKS 换手率来自腾讯 `stock_zh_a_hist_tx` 的 `turnover`；
2. 该口径是**流通股本**；
3. 同花顺显示的是**自由流通股本**（剔除限售/大股东长期持有）；
4. 「两者对同一只票可以差出一大截」→ 需补自由流通口径。

实测逐条核验，**第 2 条成立，第 3/4 条不成立**。

## 2. 腾讯 `turnover` 的分母到底是哪个？（实测确证）

选「流通股本 ≠ 总股本」的票做判别式 —— 用
`隐含分母 = 当日成交量(股) ÷ 当日换手率`
反推，与东财 `f84`(总股本) / `f85`(A股流通股本) 比对。

| 代码 | 名称 | 总股本 | A股流通股本 | 腾讯隐含分母 | 结论 |
|---|---|---|---|---|---|
| 688981 | 中芯国际 | 85.62 亿 | **20.01 亿** | **19.93–20.05 亿** | = A股流通股本，**非**总股本 |
| 601857 | 中国石油 | 1830.21 亿 | 1619.22 亿 | 1548–1751 亿 | = A股流通股本 |
| 601728 | 中国电信 | 915.07 亿 | 776.30 亿 | 745–795 亿 | = A股流通股本 |
| 601118 | 海南橡胶 | 42.79 亿 | 42.79 亿 | 42.77–42.87 亿 | 二者相等，无法判别 |

**结论**：腾讯 `turnover` 的分母 = **A股流通股本**（= 东财 push2 `f85` = F10 `LISTED_A_SHARES`），既非总股本，也非自由流通股本。

## 3. 同花顺自家 feed 的分母（实测确证）

同花顺日线接口 `https://d.10jqka.com.cn/v6/line/hs_<code>/01/last.js` 返回
`日期,开,高,低,收,成交量(股),成交额,换手率(%),...`（字段 8 = 换手率）。

用中芯国际（流通 20.0 亿 ≪ 总股本 85.6 亿）判别：

| 日期 | 同花顺字段8 | 按 A股流通股本(20.01亿) 算 | 按总股本(85.62亿) 算 |
|---|---|---|---|
| 2026-09-15 | 1.276% | **1.276%** ✅ | 0.298% ✗ |
| 2026-09-16 | 1.971% | **1.971%** ✅ | 0.461% ✗ |
| 2026-09-17 | 1.225% | **1.225%** ✅ | 0.286% ✗ |

**结论**：同花顺自家 feed 用的是 **A股流通股本** 口径 —— 与腾讯**同分母**。
（这与 issue 前提 3「同花顺 = 自由流通」直接冲突。）

## 4. 逐日核对：PIKS vs 同花顺（22 只 × 各 140 交易日）

issue 的**生产实证票 601118**，其生产实证日 2026-09-08（`max_turnover: 7.52`）：

| 日期 | PIKS(腾讯×100) | 同花顺 feed | 差 |
|---|---|---|---|
| 2026-09-04 | 4.690% | 4.690% | 0.000 |
| 2026-09-07 | 5.900% | 5.897% | 0.003 |
| **2026-09-08** | **7.520%** | **7.522%** | **-0.002** |
| 2026-09-09 | 7.270% | 7.272% | -0.002 |
| 2026-09-15 | 3.360% | 3.361% | -0.001 |
| 2026-09-17 | 4.240% | 4.235% | 0.005 |

扩大到 **22 只跨板块股（沪主板/深主板/创业板/科创板）× 各 ~140 个交易日**：

```
  代码     样本日数       最大偏差       平均偏差  判定
  600000      140    0.0050%    0.0024%  一致
  601118      140    0.0050%    0.0024%  一致   ← issue 实证票
  688981      140    0.0050%    0.0025%  一致   ← 流通≠总股本
  601857      140    0.0050%    0.0024%  一致   ← 两者差距最大
  300059      140    0.0180%    0.0042%  一致   ← 全场最大偏差
  000651      140    0.0070%    0.0025%  一致
  …
不一致样本: 无（全部 ≤0.02%）
```

残差量级 = 腾讯 turnover 只给 4 位小数的**舍入误差**（0.0001 × 100 = 0.01%），非口径差异。

**结论**：PIKS 换手率与同花顺**逐日一致**（最大偏差 0.018%，平均 0.0025%）。

## 5. 自由流通口径：无免费源（穷举实测）

| 候选源 | 实测结果 |
|---|---|
| akshare 个股接口 | 无。`自由流通市值` **仅存在于 CNI 指数成分**（`index_detail_cni` / `index_detail_hist_cni` / `index_all_cni`），1090 个接口里唯一命中 |
| 东财 push2 快照 | `f84`=总股本、`f85`=A股流通股本，**无自由流通字段** |
| 东财 F10 股本结构 | `TOTAL_SHARES` / `LISTED_A_SHARES` / `LIMITED_SHARES` / `H_FREE_SHARE`，**无自由流通** |
| 同花顺 realhead | `402`=总股本、`407`=流通股本，**无自由流通** |
| 同花顺 F10 网页 | JS 渲染，源码无 |
| 问财 (iwencai) | 403 Forbidden |
| 雪球 | 需 `xq_a_token`，匿名 400 |
| 东财 `stock_zh_a_hist` / `stock_individual_info_em` | 本机 WAF 限流不断连（RemoteDisconnected） |

**结论**：在 issue 明示「不接付费数据源」的约束下，**自由流通口径不可得**。

## 6. 因此的处置

1. **不改口径** —— 改自由流通反而会**破坏**与同花顺的一致性（当前一致）。
2. 修正措辞：现有文案「拿不到同花顺自由流通口径」会让读者以为「同花顺 = 自由流通口径、两边不一致」，与实测相反。改为如实表述：**= A股流通股本口径，与同花顺一致**。
3. 顺带发现（未夹带，另开 issue）：`get_quote` 未做 `×100`，`Quote.turnover` 是小数而 `Bar.turnover` 是百分数 —— 单位不一致；但该方法当前**无任何消费方**（死代码）。

## 7. 唯一未验证项（如实标注）

本节全部基于**同花顺公开 feed**。用户所见若为同花顺 **App** 上另有一列「实际换手率」（自由流通口径），则那是 App 专属字段，非本实测的 feed 字段 —— 需用户提供 App 截图/列名方能对齐。本实测**未**覆盖 App 内可能存在的第二列。
